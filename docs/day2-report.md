## 需要注意的数据事实

**调和油规格发生了真实文字定义变化。** 2026-10-13由“金龙鱼调和油，5升桶装”改为“主销品牌调和油，5升桶装”，因此分别保留98期、7期两条序列。猪肉四个部位也分别保留。大蒜、籼米、苹果、香蕉和鸡肉仅空格、标点不同的组合按明确映射合并。

**无报价与缺期含义不同。** 162条 `-` 对应显式无报价，价格为null；季节性商品未出现的周不生成报价。程序不补0或插值，不把桶、袋与500克混算。

**质量提示保留原价。** 727条记录触发提示，其中709次为单市场周变动达到30%，20次为价格不超过当期同商品中位数的一半，二者有重叠。这些条目用于人工复核，不直接认定为错误，也没有从汇总中擅自删除。

**37条候选尚未训练模型。** 入选需要至少52期覆盖充足历史、历史覆盖至少90%、最近连续26周覆盖充足；每期至少15/18个市场有有效价格。未入选7个规格为白油菜、空心菜、豇豆、豌豆尖、鲜牛肉和两种调和油，具体原因在候选CSV中。另有104周连续覆盖标记，模型阶段仍需安排足够训练与回测区间。

完整口径见 [清洗规则](cleaning-rules.md)，字段与SQL示例见 [数据仓库结构](warehouse-schema.md)。
