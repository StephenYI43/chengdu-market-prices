## 数据与技术落实

API版本为0.3.0。新增overview、products、markets、prices、trends、comparisons和CSV导出7个读取入口，契约见 [接口说明](api-contract.md) 与 `contracts/openapi.json`。

前端延续React 19、TypeScript 7和Vite 8，新增锁定的Apache ECharts 6.1.0。按官方模块接口仅引入折线图、柱状图、需要的组件与SVG渲染器，并延迟加载图表模块；同时提供可读的数据表。组件使用ResizeObserver跟随布局变化，卸载时释放图表实例和监听。

前端在本机打包，静态文件随API镜像一起运行，同端口访问，无需另起常驻Vite服务。Spark、Kafka和依赖版本保持原先锁定配置。镜像构建与启动脚本增加前端构建及API存活检查。

每次分析先固定 `run_id=20261124-day2-verified`，之后所有请求都读取该批次。数据库以只读方式打开，异常仓库返回503，未找到商品或市场返回404，非法参数返回422。数值价格在JSON中保持十进制字符串，浏览器仅在绘图和显示时转换。
