# 全量清洗与预测入选规则

## 输入与来源

使用用户提供的长表和宽表CSV。首先按原始商品规格和市场展开宽表，对所有字段值及其出现次数与长表作完全比对，再保留源文件SHA-256、CSV记录序号、原始字段和来源栏目网址。记录序号从第一条数据起为1，不包含表头，也不等同于包含换行引号时的物理文件行号。

源文件保留在 `D:/bigdatasource`；尚未逐期对照官网。报价日期是周度业务日期，源文件没有逐条原始发布时间或修订历史。

## 商品、市场与单位

- [规格映射](../config/product-aliases.csv)逐项维护原始名称、规格、单位与规范值。53条原始组合对应44个商品规格。
- 仅允许去空格和中英文逗号、顿号后的文字一致；程序拒绝品牌、等级或部位的语义合并。同一商品ID的规范名称、规格、单位和分类必须一致。
- 大蒜、籼米、苹果、香蕉和鸡肉的版式差异被合并；猪肉四个部位分别保留。
- “金龙鱼调和油，5升桶装”和“主销品牌调和油，5升桶装”是不同商品ID。2026-10-13形成一条规格更换审计记录。
- [市场表](../config/markets.csv)保留6个来源分组和18个市场。“高新”为原监测分组，不据此推断行政区划。
- 元/500克、元/桶、元/袋分开统计。未将桶、袋换算为重量，也没有按销量加权的基础数据。

商品ID使用规范名称、仅排版规范化后的规格和单位计算；市场ID使用区和市场名称计算。SHA-256算法固定，未使用受排序或批次影响的自增编号。单条业务键和事件ID与第一天真实回放使用相同算法，来源记录ID另由文件哈希与CSV序号确定。

## 报价清洗

| 情况 | 处理 |
|---|---|
| 合法正数价格 | 解析为Decimal(12,4)，保留原字符串 |
| 原值为 `-` | price=null，quote_status=missing，missing_reason=source_no_quote |
| 空必填字段、非法日期、非法或非正数价格 | 写入隔离表及具体原因 |
| 未登记规格、市场或单位 | 写入隔离表，需维护映射后重新运行 |
| 同业务键且数值、状态相同 | 保留最早源记录，重复组进入审计表 |
| 同业务键出现不同价格或状态 | 整组隔离，不任意选一个覆盖 |

本次没有非法、冲突或重复记录，75,726条全部保留。校验器采用当前快照的严格验收：出现隔离或重复记录会阻止发布，保留上一个可用批次，供核查后重新运行。质量提示不会改变价格。缺期不扩充为虚构报价，无报价不补0、不插值。

## 周度汇总与比较

全市口径是18个监测市场范围内同周、同商品规格的有效市场等权均值，不是按全市消费量加权的价格指数。区级口径在所属市场内同样计算。每组同时保存观察市场数、有效市场数、无报价数和目标市场数，避免只看均价而忽略覆盖变化。

均值与中位数四舍五入到4位小数；保留最低价、最高价、价差和总体标准差。少于两个有效市场时，排名标识为不可用。所有比较固定商品ID，因此单位、品牌和部位不会混合。

`wow_change` 仅比较相隔7天的相邻报价期。前期无有效均价或跨越缺期时为空。另保存 `common_market_wow_change`：先匹配连续两期都有有效价格的相同市场，再以本期配对市场均价除以前期配对市场均价减1，并返回配对市场数。这能帮助识别市场构成变化造成的均价波动；页面展示应同时说明覆盖数。

## 质量提示

[规则文件](../config/curation-policy.json)版本为1.0.0：

- 同商品、同市场、相隔7天的价格涨跌幅绝对值达到30%，提示 `large_weekly_change`。
- 当期价格达到同商品市场中位数的2倍，提示 `high_vs_peer_median`。
- 当期价格不超过同商品市场中位数的一半，提示 `low_vs_peer_median`。

这些是便于检查的工程阈值，不代表已认定错误或完成业务预警。本次727条记录触发提示；709次周变动提示、20次低于同业中位数提示存在重叠，不可直接相加当作记录数。所有提示可追溯至原CSV记录号。

## 预测序列候选

当前目标为监测市场的商品周均价。每一期至少15/18个市场有有效价格才计为覆盖充足的一期。首批基线候选需要同时满足：

1. 至少52期覆盖充足的历史。
2. 从首次观测至本次截止期，覆盖充足期占比至少90%。
3. 截止期向前至少26个连续周覆盖充足。
4. 当前报价期覆盖充足。

计算按指定 `as_of` 截断，忽略未来记录和截止期后才出现的商品。年度季节性候选额外标记最近104周连续覆盖，但是否有足够训练期与回测期仍需模型阶段决定。

截至2026-11-24，44个规格中37个满足首批条件。未入选7个：白油菜、空心菜、豇豆、豌豆尖、鲜牛肉以及两种调和油规格。原因包括季节性缺期、当前不再报价或只有7期历史。候选名单不表示已经获得预测准确率。

后续回测需在每个历史截止期重新选序列、生成滞后特征和拟合预处理器，按时间滚动划分，禁止随机打散周数据。原报价期内的质量提示和当期市场中位数属于审计信息，不能直接作为提前预测当周价格的已知特征。

## 校验与发布

Python读取原始CSV独立计算逐条字段及全部周汇总，DuckDB读取Spark Parquet并校验；预测覆盖额外用独立SQL日历连接复算。价格和标识精确比较，标准差及变化率允许1e-7数量级的浮点容差。

每次运行使用新的批次目录，拒绝覆盖已有批次。通过全部校验后才生成可移植的DuckDB物理表，并原子替换 `runtime/warehouse/current.json` 指针。中途失败不会切换当前批次。历史运行目录保留，以便检查与复现。
