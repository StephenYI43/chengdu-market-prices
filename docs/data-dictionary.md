# 成都农贸市场价格数据字典

## 来源和粒度

输入为用户提供的成都市发改委市场价格栏目采集结果。原文件位于 `D:/bigdatasource`，只读使用。首期范围为2024-11-26至2026-11-24，共105个周二报价期。尚未逐期对照官网原文。

长表一行表示一个报价日、一个商品规格、一个市场的报价状态。原始总数75,726，其中有效数值价格75,564，`-`无报价162条。共有6个区、18个市场、40个商品名称和53个原始名称规格组合，53不代表53种独立食品。空格标点差异将由第二天的规格映射处理。

| 原始列 | 标准字段 | 类型 | 规则 |
|---|---|---|---|
| 日期 | quote_date | date | 业务报价日，保留原日期，不转换成发送时间 |
| 商品名称 | product_name | string | 必填，真实商品名称 |
| 产品规格 | product_spec | string | 保留原文；规范映射另行保存 |
| 计量单位 | unit | enum | 元/500克、元/桶、元/袋 |
| 区 | district | string | 原监测分组，包含高新，不强行改为行政区定义 |
| 市场 | market | string | 与区共同标识市场 |
| 价格 | price_raw | string | 原报价；`-`为无报价 |
| 价格解析值 | price | decimal(12,4)或null | 有报价必须大于0；缺失不补0 |

## 消息补充字段

| 字段 | 含义 |
|---|---|
| schema_version | 契约版本，当前1.0 |
| business_key | 报价日、商品、规范规格、单位、区和市场的SHA-256 |
| event_id | 源文件哈希、业务键、原报价的SHA-256，用于重复事件识别 |
| batch_id | 一次入库或回放批次标识 |
| mode | live或historical_replay，验证样例始终为后者 |
| quote_status | quoted或missing |
| source_url | 已知来源网址；首日仅保存栏目网址，不编造每期详情地址 |
| source_file_sha256 | 完整输入长表的哈希，用于追溯 |
| ingested_at | 带时区的处理到达时间，与quote_date分离 |

## 统计约定

- 商品周均价：同周同商品规格的有效市场等权均值，同时返回有效市场数。
- 区周均价：同区同周同商品规格的有效市场均值。
- 市场价差：同周同商品规格的最高价减最低价。
- 元/桶和元/袋不与元/500克直接平均。
- 季节性商品停止报价不补成0，牛肉等短历史商品不进入首批预测。
- 各单位价格的合计只能作为传输完整性校验，不能作为业务指标。

## 第二天落实情况

53个原始组合已映射为44个独立商品规格，具体规则与映射表见 [清洗口径](cleaning-rules.md)。原始字段保留，新增价格解析、稳定ID、缺失原因、覆盖数、同市场周变动与质量提示等字段，见 [数据仓库结构](warehouse-schema.md)。
